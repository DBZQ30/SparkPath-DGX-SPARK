# 节奏节点口径（通用建议 + 官方硬节点）

> **性质**：本文件是**通用建议模板**（依据培养方案修读说明、《三类培养模式实施细则》、选课指南、转专业细则提炼），
> **不是学校硬性规定**。SKILL 输出中：通用建议标注「建议」，官方硬节点标注「★官方」。

## 1. 官方硬节点（来源明确）

| 节点 | 来源 | 说明 |
|------|------|------|
| 培养模式申请：**大三第二学期** | 《三类培养模式实施细则》+ 各专业培养方案 | 书面申请 → 学院审批 → 参加对应类型毕业设计；审批不通过按常规型，已修课程/成果仍按规定认定 |
| 每学期修读**不超过 N 学分** | 各专业培养方案（六）课程要求 | N 逐专业：工商管理/大数据 25、工业工程 27、会计学（ACCA）30；前一学期学分绩 > 90 可适当超出 2 学分 |
| 转专业：**第三学年结束前修完补修课程** | 转专业实施细则 | 否则不得参加当年免试研究生推荐（推免红线） |
| 转专业：**转入会计学（ACCA）须降级就读** | 转专业实施细则 | 大一/大二/大三转入均适用 |
| 转专业：**只允许填报 1 个专业志愿**（提交后不可改） | 转专业实施细则 | 笔试（高等数学 I + 英语）+ 面试各占 50% |
| 专业选择：**按顺序选报 3 个专业志愿** | 专业选择实施方案 | 「专业志愿优先，遵从综合成绩」；综合成绩 = 70% 学业 + 20% 专项考查 + 10% 综测 |

## 2. 通用建议模板（非官方）

| 阶段 | 学业 | 竞赛 | 科研 | 证书 / 其他 |
|------|------|------|------|-------------|
| 大一（1-1/1-2） | 夯实通识与基础；军训 1-1 完成；英语/体育起步；**大一第二学期专业选择（分流）** | 数学建模校赛、学科入门赛 | 参加实验室开放日、导师宣讲 | 英语四级（1-2~2-1）；适应选课规则 |
| 大二（2-1/2-2） | 大类平台 + 专业基础；关注先修链 | 大创申报（春秋两季）、专业基础竞赛 | **联系导师、进课题组**（科学研究型建议此时段） | 英语六级；计算机等级；专业入门证书 |
| 大三（3-1/3-2） | 专业核心/选修；**研究生进阶课程**（科学研究型）/ **跨选课程**（交叉融合型） | 高级别竞赛（榜单内）、成果转化 | 科研训练与实践、论文/专利起步 | **大三第二学期提交培养模式申请**；确定毕设方向；专业类证书 |
| 大四（4-1/4-2） | 专业选修收尾；毕业设计（第七学期选题、第八学期撰写） | 收尾/获奖 | 毕设与科研衔接 | 学分自查；考研/保研/就业 |

## 3. 四方向差异（速览）

| 方向 | 核心替代规则 | 范围约束 | 申请/毕设 |
|------|--------------|----------|-----------|
| 常规型 | 无 | — | 常规型毕业设计 |
| 科学研究型 | 修读**本学科研究生进阶课程** ≥ 6/8 学分替代专业选修课 | 本专业公布的研究生进阶课程清单 | 大三第二学期申请；科学研究型毕设 |
| 交叉融合型 | 修读**某确定跨选专业的交叉课程** ≥ 6/8 学分替代专业选修课 | **只交叉融合一个专业**（本专业公布范围） | 大三第二学期申请；交叉融合型毕设 |
| 创新创业型 | **创新创业成果**替换集中实践 ≥ 6 学分 | 除毕业设计和军训外；成果类别：大创/竞赛/创办企业 | 大三第二学期申请；创新创业型毕设 |
