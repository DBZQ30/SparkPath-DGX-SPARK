# 选课合理性评分口径 (scoring-rules)

本文件是 `academic-warning` skill 的评分细则，供与命令实现对照、审阅与回归。
**实现为准：** `academicwarning/selection_check.py`（核心计算）与 `academicwarning/rules.py::Prep`（索引 / 匹配 / 豁免语义）。口径变更请同步代码与本文件（不在此处再引用其他文件，保持引用距 SKILL.md 一层）。

## 目标

判断“回避专业选修、只攻必修”等不符合培养计划的选课：对每个在籍学生，比较**培养计划应修**与**已修 + 本轮已选**，标出仍有缺口的类别，以及逐门缺修的必修课。

## 数据源

| 数据 | 来源 | 作用 |
| --- | --- | --- |
| 选课结果（xlsx） | 管理员在小程序“学业预警”页上传 | 本轮选课，按年级取最新 |
| 学籍名单 | 同上 | 学生基准名单、专业、班级 |
| 成绩单（每专业一份） | 同上 | 已修课程与成绩（学号图片 OCR） |
| 培养方案学分结构 JSON | 同上 | 应修学分口径基准 |

## 1. 应累计（应修学分，per 类别）

- 以**培养方案学分结构 JSON** 的毕业要求 / 进度口径为准，共 8 类。
- **模块课程、专业选修课程 = 毕业要求全量**（不受当前学期限制）。
- 其余类别 = `开课学期 ≤ 当前学期` 的课程学分合计，并**剔除“全员无成绩”课程**（成绩未出 / 未开课，复用 `Prep._compute_missing_courses`）。
- 当前学期由选课文件“学年学期”+ 学生年级推导（如 2023 级在 2026-2027 第一学期 = `4-1`）。

## 2. 已修（per 类别，及格制）

- 同一课程（clean 名）多行取**最高分代表行**（`parsers.representative_by_course`；缺考 / 空 = 0 档）。
- **仅代表行及格（`pass_flag=1`）才计学分**：挂科 / 缺考不计；补考 / 重修通过只计一次。
- 类别归类（`_grade_category`），按顺序：
  1. 命中培养方案课程（`_match_plan_course`，含 ACCA 新旧代码映射 / 子串 / 标记归并）→ 方案类别（“数学和基础科学类课程”归并为“学科门类基础课程”）；
  2. 未命中但成绩单标记 `◆选修课` / `◇核心课` → 模块课程；
  3. 未命中且课程名含英语类关键词（英语 / 雅思 / 托福 / 视听说）→ 公共课程；
  4. 课程名含“军训” → 集中实践；
  5. 仍无法归类 → **不计入**（方案外课程）。

## 3. 已选（per 类别）

- 本轮选课结果中各类别学分（`Prep.selected_credits_by_category`）。
- **跨选课 / 辅修课程排除**，不计入缺口。
- 通识选修学分以**通识课程信息表**为权威，回落众数 / 2.0 估算（`gen_ed_credit_override`）。

## 4. 缺修必修课（逐门，只看及格）

- 取**应修必修课**（`开课学期 ≤ 当前学期`，剔除“全员无成绩”课程）。
- 判为缺修：代码不在「已及格匹配课程代码 ∪ 本轮已选课程代码」中。
- `reason`：
  - `unattempted` — 从未修过；
  - `failed` — 有成绩但最高分不及格，`score` 附代表行成绩原文（前端旁注）。
- 留学生（学号含 `999` 段）豁免思政类与军训 / 国防教育 / 军事理论类必修课。

## 5. 触发条件

对每个在籍学生，满足任一即触发提醒：

- **任一类别** `应累计 − 已修 − 已选 > 0`（`round` 到 1 位小数后比较，**差额 0.5 / 1.0 也触发**）；
- 或存在 **≥1 门缺修必修课**。

边界：

- 非在籍学生不参与；
- 某专业**没有任何成绩记录** → 跳过该专业学生（防假阳性）；
- 结果行取**差额最大的类别**作为展示四要素；无类别差额但有缺修必修课时，四要素填缺修必修课学分合计。

## 6. 豁免 / 特殊处理

- **全员无成绩课程**：从“应累计 / 缺修”中剔除（数据侧豁免），受影响课程写入选课文件 meta 的 `exempt_courses`，供管理员核对。
- **单生豁免**（`_apply_waivers`）：
  - 类型 A：虚拟成绩行标记 `WAIVER_MARK="特殊豁免"`，不计专业覆盖（R1）；
  - 类型 B：旧课学分在计算源头叠加到对应类别（N3）。
- **成绩待出豁免**：开课学期在“成绩单覆盖最大学期”与“当前学期”之间的课程，成绩单无记录 ≠ 未修，不参与缺修判定。

## 7. 摘要输出

`build_summary`：

```
选课检查完成：检查 N 人，选课不合理 M 人（<专业> x 人…）；任一类别差额>0 学分即触发提醒
```

另附：名单内本学期未选课学生（需管理员核实）、豁免提示、导出报告文件名。

## 已知边界

- 只覆盖选课合理性；不产出挂科 / 学分缺口 / 进度落后的完整预警。
- “应累计”依赖学分结构 JSON 的准确性；JSON 与方案正文不一致时会按 JSON 计算。
